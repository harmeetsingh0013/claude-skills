## Diagrams

### Component Architecture

The Redirect Handler and Click Consumer components and their data/queue
dependencies.

```mermaid
flowchart LR
    Redirect["Redirect Handler"]
    Consumer["Click Consumer"]
    DB[("Database")]
    Queue[["Click Event Queue"]]
    Redirect --> DB
    Redirect --> Queue
    Queue --> Consumer
    Consumer --> DB
```

### Request Flow

The redirect path through async click-event publication.

```mermaid
sequenceDiagram
    participant V as Visitor
    participant R as Redirect Handler
    participant D as Database
    participant Q as Click Event Queue
    V->>R: GET /r/{code}
    R->>D: Lookup code
    D-->>R: Original URL
    R-->>V: 302 Redirect
    R->>Q: Publish click event (async, per ADR-003)
```
